# Lezionify 0.2.5

## Novità

- Collegamento facoltativo al widget Android: mostra tempi di studio e lezioni
  ancora da completare per i corsi attivi. L'applicazione Android va installata
  separatamente.
- Le Impostazioni permettono di attivare un repository dati GitHub dedicato,
  mostrare il codice di abbinamento e richiedere un aggiornamento.

## Dati e riavvio

L'invio e' disattivato finche' non viene configurato esplicitamente. Il
riepilogo viene cifrato sul PC e include nomi dei corsi, tempi aggregati e
conteggi; audio, trascrizioni e dispense non vengono inviati tramite questa
funzione. Credenziali e chiave sono protette dal sistema operativo. Il
repository pubblico conserva cronologia e metadati dei file cifrati. Per
configurazione e limiti vedere `docs/product/statistiche-android.md`.

Chiudere i lavori e salvare le modifiche prima dell'aggiornamento.

## Limiti noti

Il percorso e' stato collaudato con dati sintetici sul telefono, non ancora con
le statistiche personali. Il codice di abbinamento si trasferisce manualmente;
la scansione QR non e' disponibile. Android puo' ritardare gli aggiornamenti
periodici; il widget mostra l'ultima copia con la sua data. Il PC non invia dati
quando Lezionify e' chiuso. Per l'uso serve un repository pubblico dedicato e un
token GitHub personale con accesso limitato al repository.

Installer Windows non firmato: SmartScreen puo' mostrare un avviso. Upgrade tra
installazioni reali, UAC e SmartScreen non collaudati; nessun rollback automatico
dei dati. Rimane noto il download del modello pubblico della ricerca semantica
interrotto nella 0.2.2; questo aggiornamento non modifica quel runtime.
