# Screenshot per README e portfolio

I tre SVG presenti in questa cartella sono segnaposto temporanei. Prima del lancio pubblico:

1. usa dati fittizi o completamente anonimizzati;
2. cattura l'app a 1440×900 o con un rapporto vicino a 16:9;
3. evita chiavi API, nomi reali, percorsi locali e trascrizioni universitarie autentiche;
4. esporta immagini PNG ottimizzate, idealmente sotto 1 MB ciascuna;
5. aggiungi `dashboard.png`, `lecture.png` e `study.png` in questa cartella;
6. sostituisci nel README i riferimenti `*-placeholder.svg` con i rispettivi PNG.

Scatti consigliati:

- `dashboard.png`: panoramica della Dashboard con statistiche e corsi fittizi;
- `lecture.png`: player, dispensa Markdown, formula KaTeX e diagramma Mermaid;
- `study.png`: quiz o flashcard con una sessione di studio in corso.

Per LinkedIn è utile anche una quarta immagine verticale o quadrata che mostri il flusso “audio → trascrizione → dispensa”.
